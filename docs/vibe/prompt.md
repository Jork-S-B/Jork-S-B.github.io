## 文本提示词

1. 立角色
2. 述问题: 背景信息
3. 定目标
4. 补要求: 输出要求、少量示例、md格式

```markdown
# 角色
你是一名有 8 年经验的 SaaS 产品经理，擅长竞品分析、增长策略和 B 端产品设计。

# 背景问题
我们是一款面向中小电商的 AI 客服工具，刚进入市场。主要竞品有：
- 竞品 A：价格低，但回答准确率一般；
- 竞品 B：大厂背景，集成能力强，但部署成本高；
- 竞品 C：垂直电商经验多，但多语言支持弱。
我们想知道下一版产品应该优先打什么差异点。

# 目标
输出一份竞品分析摘要，帮助团队判断：
1. 我们的核心机会点；
2. 下一版最值得投入的 3 个功能；
3. 不建议跟进的 2 个方向。

# 输出要求
- 必须使用 Markdown 格式。
- 结构固定为：
  1. 一句话结论
  2. 竞品对比表
  3. 机会点
  4. 功能优先级
  5. 风险提醒
- 输出要求：观点明确，少用“可能”“也许”，每条建议给出理由。
- 少量示例：
  - 竞品对比表列名示例：竞品 | 目标客户 | 核心优势 | 明显短板 | 可借鉴点
  - 功能优先级示例：P0：多语言自动回复；理由：竞品 C 弱，跨境客户强需求。
- 禁止编造未提供的市场数据；不确定处标注“需验证”。

```

## 图像生成提示词

正向 + 负向（不该出现的内容）

- 主体: 主体做什么动作，有什么特征
- 细节: 人物细节（情绪、特征等）、材质、氛围环境、光照、配色、镜头构图、画面质量等
- 风格参考: 画面风格、艺术家风格、渲染方式等

=== "正向提示词骨架"

    ```md
    # 主体
    主体做什么动作，有什么特征。

    # 细节
    人物细节：情绪、特征、服装、材质。
    环境氛围：场景、天气、时间。
    光照配色：光线方向、色温、主色。
    镜头构图：景别、角度、镜头、景深。
    画面质量：分辨率、渲染质量、电影感。

    # 风格参考
    画面风格、艺术家风格、渲染方式。
    ```

=== "雨夜赛博朋克机械猫"

    ```md
    正向提示词：
    主体：一只银灰色机械猫，蹲在霓虹灯下的拉面摊前，抬头看招牌，尾巴缓慢摆动。
    细节：情绪好奇又警惕；金属外壳有划痕和雨滴，关节处露出暖色灯带；雨夜街道，蒸汽从地面升起；霓虹粉蓝与暖黄交织，主色为青蓝、品红、黑色；低角度中近景，35mm 镜头，浅景深；8K，电影级质感，体积光，细腻反射。
    风格参考：赛博朋克 2077 概念艺术，押井守《攻壳机动队》氛围，Blender Cycles 渲染，写实 3D 动画风格。

    负向提示词：
    低分辨率，模糊，过曝，欠曝，畸形，多余肢体，多余尾巴，脸部扭曲，文字，水印，logo，签名，塑料感，恐怖，血腥，战争，杂乱背景，错误透视，比例失调。
    ```

## 多模态提示词

- 结构化: 明确任务背景 + 模板约束 + 结构化输入输出
- 明确模态分工: 分职责、协同整合、精准指令
- 迭代优化: 生成、评估、调整，循环持续优化，并以错误驱动改进。

```markdown
# 任务背景
你是一名多模态电商内容助手。用户会提供一张商品图片和一段商品卖点文本。你需要根据图片真实内容和文本信息，生成小红书种草文案。

# 输入模板
- 图像：{image}
- 商品名称：{product_name}
- 卖点文本：{selling_points}
- 目标人群：{target_audience}
- 平台：小红书

# 输出模板
必须只输出以下 Markdown：

## 标题
不超过 20 字，带 1 个 emoji。

## 正文
120-180 字，口语化，分 2-3 段。

## 卖点提炼
- 卖点 1：
- 卖点 2：
- 卖点 3：

## 标签
#标签1 #标签2 #标签3 #标签4 #标签5

# 约束
- 不得编造图片中不存在的细节。
- 不确定的信息标注“以实物为准”。
- 不使用绝对化承诺，如“100% 有效”“全网最低”。

# 模态分工
1. 图像理解职责：
   - 识别商品外观、颜色、材质、使用场景、画面风格。
   - 只描述图片中真实可见的内容。
2. 文本理解职责：
   - 提取商品名称、核心卖点、目标人群、禁用词。
   - 区分“事实信息”和“营销表达”。
3. 协同整合职责：
   - 用图像信息增强文案真实感。
   - 用文本卖点补齐图片无法表达的功能。
   - 若图文冲突，以文本事实为准，并在输出中标注“需确认”。
4. 精准指令：
   - 不得把图像中的 A 商品写成 B 商品。
   - 不得把“可能”写成“一定”。
   - 每个卖点必须能追溯到图片或输入文本。

```
